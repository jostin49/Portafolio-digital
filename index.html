Proyectos Destacados

Soluciones aplicadas que resuelven necesidades reales con codigo estructurado y repositorios abiertos.

EcoScan — Clasificacion de Residuos

Sistema de inteligencia artificial que clasifica imagenes de residuos en 9 categorias usando un ensemble de 4 CNNs. El usuario sube una foto y recibe la categoria del residuo junto al porcentaje de confianza.

🎯 Problema que resuelve

Mas del 90% de los residuos reciclables terminan en rellenos sanitarios por clasificacion incorrecta. EcoScan permite identificar correctamente que tipo de residuo se tiene y como reciclarlo.

PythonTensorFlowFastAPIDockerCNN Ensemble
Repositorio GitHub

CuentIA — Cuentos Infantiles con IA

Plataforma digital basada en IA que genera cuentos infantiles personalizados segun nombre, edad, intereses y valores del nino. Integra NLP para el texto narrativo y TTS para la narracion en audio.

🎯 Problema que resuelve

La escasez de contenido educativo personalizado para ninos. CuentIA permite a padres y educadores crear historias unicas adaptadas al perfil lector con biblioteca personal y seguimiento del progreso.

PythonDjangoReactNLPTTS
Repositorio GitHub

AgroMercado — E-commerce Agricola

Plataforma web de comercio electronico para la venta de productos de cuatro sistemas de produccion: acuicola, pesquero, ganadero y vegetal. Incluye chatbot de asistencia al usuario y secciones dinamicas por categoria.

🎯 Problema que resuelve

La falta de canales digitales accesibles para productores agricolas. AgroMercado permite mostrar y simular compras del sector primario con interfaz clara y accesible.

ReactNext.jsTypeScriptHTML/CSS
Repositorio GitHub

GUIOSPRO-FLOSS — Evaluacion de Software Libre

Herramienta de evaluacion de adopcion de software FLOSS. Evalua 18 factores clave con grafico radar de resultados y exportacion a PDF. Historial de evaluaciones persistido en PostgreSQL.

🎯 Problema que resuelve

La ausencia de herramientas estructuradas para medir objetivamente la viabilidad de adoptar software de codigo abierto en organizaciones. Genera reportes tecnicos reproducibles.

ReactTypeScriptViteFastAPIPostgreSQL
Repositorio GitHub
